Before you start

Words you will see

Vector
A list of numbers, such as [0.9, 0.1]. A token (a word or piece of a word) is represented as a vector.
Matrix
A rectangular table of numbers. Multiplying a matrix by a vector gives a new vector. A matrix with r rows and c columns turns a length-c vector into a length-r vector.
Dot product
Multiply matching entries and add them up. [a, b] · [c, d] = a·c + b·d. A bigger dot product means the two vectors point in more similar directions.
Softmax
Turns a list of scores into weights. Raise e to each score, then divide each by the total, so every weight is positive and the weights sum to 1. Bigger scores get more weight.
Parameter
One number the model learns during training. A weight matrix is a block of parameters, and counting parameters means counting every entry in every learned matrix.
Residual connection
Adding a sublayer's input back to its output: f(x) + x. The + x is a shortcut that carries the input past the sublayer.
Layer norm
Rescales one token's numbers so they have mean 0 and a consistent spread. Defined properly in Part 6.
Index letters
i and j are positions in the sequence. i is usually the token asking a question (the query). j is the token being looked at (the key).

Part 1

What is attention?

Attention is a lookup that blends results. A normal dictionary lookup takes a query, finds one exact matching key, and returns that key's value. Attention does the same thing, except it compares the query with every key, turns those comparisons into weights, and returns a weighted average of all the values.

Each item plays one role:

  • Query: "what am I looking for?"
  • Key: "how can I be found?"
  • Value: "what do I give you if you pick me?"

The model learns all three from the data, so it learns what to look for, how to advertise, and what to pass along. The lookup is soft, meaning it blends many values with fractional weights instead of choosing one. Every step is a smooth formula, so training can use gradient descent (nudge each learned number slightly in the direction that lowers the error) on all of them.

The three steps

1. score: a_ij = how well query i matches key j (dot product, scaled) 2. weight: w_ij = softmax over j of a_ij (weights add up to 1) 3. output: out_i = sum over j of w_ij * v_j (weighted average of values)

The lecture's score is a_ij = q_i · k_j / √d_k. Here d_k is the length of each key vector. Dividing by √d_k is there because longer vectors give bigger dot products, and bigger scores make softmax put almost all its weight on a single item. Dividing by √d_k keeps the scores in a range where softmax still spreads its weight across items.

A tiny worked example, with 2 tokens and vectors of length 2

Say the query for token 1 is q_1 = [1, 0], and the keys are k_1 = [1, 0] and k_2 = [0, 1]. Let d_k = 2.

Step 1, scores: a_11 = [1,0]·[1,0] / √2 = 1 / 1.41 = 0.71 a_12 = [1,0]·[0,1] / √2 = 0 / 1.41 = 0.00 Step 2, softmax: e^0.71 = 2.03, e^0 = 1.00, total = 3.03 w_11 = 2.03 / 3.03 = 0.67, w_12 = 1.00 / 3.03 = 0.33 Step 3, output: 0.67 · v_1 + 0.33 · v_2 (a blend of the two values)

Token 1 matches its own key better, so it gets 67% of the weight. That is the whole mechanism. The widget below runs the same steps on five words.

Part 2

What is self-attention?

Self-attention is attention where the queries, keys and values all come from the same sequence. Every token looks at every token in its own sentence and decides how much to borrow from each. In "The animal did not cross the street because it was tired", the word "it" can attend strongly to "animal" and pull in that meaning.

Each token x_i is a list of d numbers. The model makes three versions of it with learned matrices. A matrix W_Q with d_k rows and d columns, times x_i, gives a list of d_k numbers. So the matrices are:

q_i = W_Q x_i W_Q has d_k rows and d columns k_j = W_K x_j W_K has d_k rows and d columns v_j = W_V x_j W_V has d_v rows and d columns a_ij = q_i · k_j / √d_k for every pair (i, j) out_i = sum over j of softmax_j(a_i) * v_j

Two things make this powerful. First, the attention pattern is computed from the data, not fixed in advance like a convolution's filter. Second, every position is computed at once. The full score table (all pairs i, j) comes out of a few matrix multiplies, which is why transformers train quickly on GPUs.

The trade-off: the score table has one entry per pair of positions, so its size grows with the square of the sequence length (T²). Part 8 covers this.

Part 4

Multi-head self-attention

One attention pattern can capture only one kind of relationship. Multi-head self-attention runs H attention operations side by side. Each head has its own W_Q, W_K and W_V, so each can learn a different pattern. One head might track which noun a pronoun refers to, and another might track the word right before. The head outputs are glued end to end into one longer list (called concatenating), and one more learned matrix mixes them into the final output.

Each head works on a slice of the model's width. With model width 512 and H = 8 heads, each head uses 512 / 8 = 64 numbers.

Grouped-query attention (GQA) keeps all the query heads but lets several query heads share one set of keys and values. During text generation, the model stores each past token's keys and values in memory so it does not recompute them. That stored memory is called the KV cache (KV means key and value). Fewer distinct key/value sets means a smaller cache.

Part 5

The transformer block

A block is a stack of a few known pieces. The whole model repeats the block L times, where L is the number of blocks. The lecture's version is pre-LN: each sublayer sees a normalized input, and its output is added back to the unnormalized residual stream (the running sum of the token's vector as it moves through the blocks).

input→LayerNorm→MHSA→ + (residual) →LayerNorm→FFN→ + (residual) →output

MHSA = multi-head self-attention. FFN = feed-forward network (Part 7). The "+" steps add the block's input back to its output.

  1. Self-attention mixes information across positions.
  2. Layer norm and residual connections keep the numbers well-scaled and let gradients flow back through many blocks. Layer norm is defined in Part 6.
  3. The feed-forward network transforms each position on its own. No position looks at another here, so all positions can run in parallel.

Why residuals? A sublayer computes f(x), and the block returns f(x) + x. If the sublayer does little at first, the output is about x, so the signal passes through unchanged and training stays stable.

Pre-LN vs post-LN: pre-LN normalizes before each sublayer (as drawn above). Post-LN normalizes after the add. Pre-LN tends to train more stably, so the lecture uses it.

Part 6

Layer norm, and the RMSNorm swap

Layer norm takes one token's vector h, which has d numbers, and rescales it. It first finds the mean μ of those numbers, then their spread σ. It subtracts the mean, divides by the spread, and then applies a learned scale γ and shift β.

μ = (1/d) · sum over i of h_i σ = sqrt( (1/d) · sum over i of (h_i − μ)² ) (divide by d, as in the lecture) LN(h) = γ ⊙ (h − μ) / σ + β

⊙ means multiply entry by entry. Here γ and β are vectors with d entries each, so each feature has its own scale and shift. The widget and Q4 use one number for γ and one for β, applied to every entry, which is the same as setting every entry equal.

RMSNorm is a simpler version. It divides by the root-mean-square of the entries and skips subtracting the mean. It also drops β. So layer norm learns 2d parameters (γ and β), and RMSNorm learns d (γ only). That difference is what Q3 counts.

Part 7

The feed-forward network and SwiGLU

The feed-forward network (FFN) processes each position on its own. The plain version takes a vector x with d numbers, multiplies it by W_1 to get a longer vector with hidden numbers (the hidden width is a size you choose, often larger than d), applies a bend φ such as ReLU (which means max(0, z): negatives become 0), and then multiplies by W_2 to return to d numbers.

Plain FFN: W_2 · φ(W_1 x) W_1: hidden × d, W_2: d × hidden

The modern version, SwiGLU, uses a gate. It computes two hidden vectors from x: one goes through a smooth bend called swish, and the other stays linear. They multiply entry by entry, so the first one controls how much of the second gets through:

SwiGLU: W_3 ( φ(W_2 x) ⊙ W_1 x ) φ(z) = z · sigmoid(z) (sigmoid squashes z into (0, 1)) W_1: hidden × d, W_2: hidden × d, W_3: d × hidden

Naming note: W_1 and W_2 have different roles here than in the plain FFN. In SwiGLU, W_2 makes the gate and W_1 makes the value being gated. The lecture also drops the biases, so these three matrices are the only learned parts.

Part 8

Cost: how local attention cuts the score table

Full attention has a score entry for every pair of positions, so a sequence of length T has T² entries. This is the main cost of attention for long inputs.

Local attention lets each position look only at a window of w neighbours. The table then has about T · w entries instead. Models often alternate local layers with global layers, so information can still travel across the whole sequence.

The FFN and attention costs depend on the model width d. For a fixed width, the FFN costs more than attention when T is below about 2d (about 1000 when d = 512). Above that length, attention's T² cost takes over.

Part 9

Encoder-only models and pre-training

A causal mask is a rule that blocks a position from looking at later positions. With it, position 3 can see only positions 1 to 3. Text generators (such as GPT-style models) use a causal mask, because they write one word at a time and cannot see the future.

An encoder-only transformer has no causal mask, so each token sees the whole input in both directions. That suits tasks that read an input and label it:

  • Sequence labelling: one label per token (for example, the part of speech of each word).
  • Sequence classification: one label for the whole input. A special token called <CLS> is added, and its final output is used to classify.
  • Span extraction: find the start and end positions of an answer inside a context.

Pre-training teaches the model general language first. The method is masked language modelling (MLM): hide some tokens, and train the model to guess them from all the other tokens, both before and after. BERT does this with a bidirectional encoder.

Q1. SwiGLU parameters

A SwiGLU feed-forward network W_3(φ(W_2x) ⊙ W_1x), with no biases, has d_model = 6 and hidden width 10. How many parameters does it have?

Show worked solution
Shapes come from the Part 7 table: W_1 and W_2 are hidden × d = 10 × 6, and W_3 is d × hidden = 6 × 10.
Each matrix has 10 × 6 = 60 entries.
Total = 60 + 60 + 60 = 180.

Q2. Multiplications for Q, K, V

A single-head self-attention layer has input dimension 8 and d_k = d_v = 4. Count an a×b matrix times a vector as ab multiplications. How many multiplications compute queries, keys and values for all positions of a length-10 sequence?

Show worked solution
Each of W_Q, W_K, W_V has d_k = 4 rows and 8 columns, so each is a 4 × 8 matrix.
One matrix times one token vector: 4 × 8 = 32 multiplications.
Three matrices per token: 3 × 32 = 96.
Ten positions: 96 × 10 = 960.

Q3. Layer norms replaced by RMSNorm

A pre-LN transformer has 6 blocks, each with 2 layer norms, plus one final layer norm. The residual dimension is 8. How many parameters are removed if every layer norm is replaced by RMSNorm?

Show worked solution
Number of norms: 6 × 2 + 1 = 13.
Residual dimension d = 8.
A layer norm learns γ and β, so 2d = 16 parameters. RMSNorm learns only γ, so d = 8.
Removed per norm: 16 − 8 = 8.
Total removed: 13 × 8 = 104.

Q4. First entry of a layer norm output

Layer norm, with σ computed by dividing by d as in the lecture, is applied to h = (7, 2, 2, 2, 2), with γ = 3 and β = 1. What is the first entry of the output?

Show worked solution
Count the entries: d = 5.
Mean: μ = (7 + 2 + 2 + 2 + 2) / 5 = 15 / 5 = 3.
Deviations h − μ: (4, −1, −1, −1, −1).
Squares: 16, 1, 1, 1, 1, which sum to 20.
Variance: 20 / d = 20 / 5 = 4.
σ = √4 = 2.
First normalized entry: 4 / 2 = 2.
Output: γ · 2 + β = 3 · 2 + 1 = 7.
